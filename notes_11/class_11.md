# React Setup Instructions

## Prerequisites

1. Install Node.js

2. Install Git Bash
- Check in bash:
- `node --version`
- `npm --version`

3. Install Create React App globally
   ```bash
   npm i -g create-react-app
   ```
   (This creates the create-react-app option globally.)

- Check in bash:
- `create-react-app --version`

## Project Setup

4. Check current directory:
   ```bash
   pwd
   ```

5. Navigate to Desktop:
   ```bash
   cd Desktop/
   ```

6. Create react directory:
   ```bash
   mkdir react
   ```

7. Navigate to react directory:
   ```bash
   cd react
   ```

8. Create React app:
   ```bash
   create-react-app first-app
   ```

## Running the Application

To open the app in VS Code:
Navigate to the app directory
Run in Git Bash:
  ```bash
  code .
  ```
  This will automatically open the Create React App in VS Code.

9. Start the development server:
   ```bash
   npm run start
   ```
