# IMDB API Integration Notes

## API Data Structure

1. Image: Poster
2. Id
3. Rank
4. Full Title
5. Imdb Rating
6. Imdb Rating Count
7. Your Review

## Package Management

- Full install: use `yarn install` instead of `npm install`
- Yarn install: `npm install -g yarn`
- Package install: `yarn add <package name>`
- Package remove: `yarn remove <package name>`

## API Setup Steps

1. Go to link: [IMDB API Documentation](https://imdb-api.com/api)
2. Go to ticket: [IMDB API Tickets](https://imdb-api.com/Account/Tickets)
3. Go to profile: [IMDB API Profile](https://imdb-api.com/Identity/Account/Manage)
4. Copy the key: `<your key>`
5. Go to swagger: [IMDB API Swagger](https://imdb-api.com/swagger/index.html)
